# assets/LICENSES.md — Lizenz-Index (Rechtsgrundlage)

Jedes Asset unter `assets/` ist hier ODER in einem der verlinkten
Bereichs-Dokumente erfasst (Datei/Ordner → Quelle → Lizenz). Regeln fürs
Reinnehmen: `docs/godot-rewrite/ASSET-INTAKE.md` §7.

**Erlaubt:** CC0, CC-BY (mit Pflicht-Credit), ausdrücklich freie Lizenzen
(z. B. Tiny-Treats-itch-Lizenzen). **Nicht erlaubt:** Unity-Asset-Store-
Standard-EULA (bindet an Unity-Projekte), Quellen ohne download-erlaubte
Lizenz, Beschaffung über Wegwerf-Accounts.

## Projektinterne Inhalte (Eigenbau)

- `character/`, `props/`, Teile von `ranch/` — Blender-Pipeline im Repo
  (`tools/blender/`), Rechte beim Projekt.
- `acui/`, `boot/`, `brand/`, `covers/`, `dlc/`, `stickers/`, `ui/`,
  `collections/`, `sky/`, `fx/`, `shaders/`, `themes` — generiertes bzw.
  handgebautes projektinternes Artwork (privates Projekt).
- `fonts/` — siehe Lizenzdateien im Ordner.
