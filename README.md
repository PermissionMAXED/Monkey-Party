# Monkey-Party

Dieses Repo trägt mehrere eigenständige Projekte. **Dieser Branch
(`cursor/gooby-godot-loop-continue`) ist die Arbeitslinie des
GOOBY-Godot-Projekts** — der kontinuierlichen Fable-Verbesserungs-Schleife
(Protokoll: [`docs/godot-rewrite/LOOP.md`](docs/godot-rewrite/LOOP.md)).

## Wegweiser (dieser Branch)

| Einstieg | Inhalt |
|---|---|
| [`GOOBY-README.md`](GOOBY-README.md) | **GOOBY 5.x** — Überblick, Ordner-Layout, Spielen/Testen (Sideload-`.ipa`), Entwickeln |
| [`UserFeedback.md`](UserFeedback.md) | Direkter Draht des Users zum Agenten (Wünsche/Bugs eintragen, Buchführung pro Welle) |
| [`docs/godot-rewrite/`](docs/godot-rewrite/) | Design-/Statusdokumente: `STATUS.md` (Ist-Stand), `EVAL-VOLLSTAENDIGKEIT.md` (ehrliche Feature-Matrix), `LOOP.md` (Schleifen-Protokoll) |
| [`GOOBY-AGENTS.md`](GOOBY-AGENTS.md) | Verbindliche Arbeitsregeln fürs Godot-Projekt (Preflight, Test-Runner, CI) |
| [`MONKEY-PARTY/`](MONKEY-PARTY/README.md) | Monkey-Party — Partyspiel (Vite + three.js + `ws`-Server); Root-Projekt von `main` |
| [`AETHERKLANG/`](AETHERKLANG/README.md) | Aetherklang — Fabric-1.21.9-Minecraft-Mod (eigenständig, JDK 21/Gradle) |
